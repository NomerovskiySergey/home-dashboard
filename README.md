# Home Dashboard

Домашній дашборд на **Guition ESP32-4848S040C_I** з ESP32-S3 і 4″ сенсорним екраном 480 × 480. Інтерфейс українською, прошивка побудована на ESP-IDF і LVGL.

- Годинник за київським часом і вулична температура обраного міста з Open-Meteo одразу поруч.
- Шестірня відкриває меню «Налаштування» з пунктами «Екран» і «Налаштування Wi-Fi».
- У «Налаштування → Система» видно стан і вік оновлень погоди, карти, типів загроз і відключень. «Перезапустити оновлення» відновлює цикл запитів; «Перезавантажити пристрій» перезапускає ESP32 після підтвердження. Wi-Fi, ключі й тема зберігаються.
- Погода, Alerts.in.ua та Alerts.energy опитуються трьома незалежними задачами: затримка одного сервісу не зупиняє інші. Карта й типи загроз залишаються разом у задачі Alerts.in.ua зі спільним лімітом запитів.
- Сторінка Wi-Fi показує стан підключення, назву мережі, IP-адресу пристрою й сигнал у dBm з оновленням кожні 2 секунди.
- Карта повітряних тривог України зі статусом території обраного міста. Дотик до карти чи статусу відкриває окремий перегляд: нерухома карта на всю ширину480px без обрізання країни та «Назад». Власні векторні піктограми ракети, БпЛА й літака позначають типи загроз для територій за Alerts.in.ua; збережені також КАБ, ППО й невідомі загрози. У лівому нижньому куті є компактна легенда всіх шести піктограм. Координат окремих повітряних цілей API не надає в задокументованій схемі. Екрани історії та деталей прибрано.
- Графік погодинних відключень на сьогодні й завтра з Alerts.energy. «Налаштування → Відключення» дозволяє вибрати область, оператора й чергу; початково — Дніпропетровська область / ЦЕК 5.2. Дотик до шкали відкриває перелік інтервалів.

## Локація

«Налаштування → Локація»: оберіть область/територію, потім місто зі списку 463 міст України. Каталог доступний без мережі; вибір зберігається після перезапуску. Типово — Дніпро. Місто визначає погоду, маркер на обох мапах і територію локального статусу тривог, також у темах PDA/Fallout. Київ і Севастополь — окремі території. Статус стосується області/території, а не підтвердженої тривоги в кожному місті.

Після зміни температура очікує нової відповіді; запізнілі дані попереднього міста відкидаються. Наявні паузи API зберігаються. Область, оператор і черга відключень налаштовуються окремо та не змінюються разом із містом.

## Налаштування відключень

Відкрийте «Налаштування → Відключення», оберіть область, оператора та чергу. Списки завантажуються з Alerts.energy і потребують Wi-Fi, ключа API та доступу за підпискою. Черги беруться з наявних записів графіків конкретного оператора; це не гарантований повний довідник усіх черг. Якщо список недоступний або порожній, скористайтеся «Оновити» чи поверніться назад.

Лише натискання черги зберігає всі три значення разом. До цього чинний графік зберігається; помилка запису залишає попередні налаштування. Новий вибір зберігається після перезапуску. При першому налаштуванні список областей за можливості прокручується до області обраного міста; це підказка, а не автоматична зміна графіка. Для наявних пристроїв без окремо збереженого вибору залишається ЦЕК 5.2 Дніпропетровської області.

## Запуск

1. Встановіть **ESP-IDF 6.1** з підтримкою ESP32-S3.
2. Зберіть і прошийте проєкт за [інструкцією запуску](docs/setup.md).
3. Налаштуйте домашній Wi‑Fi в браузері телефона. Встановіть власні ключі API для тривог і графіка через USB.
