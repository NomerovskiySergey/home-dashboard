# Home Dashboard

Домашній дашборд для Дніпра на **Guition ESP32-4848S040C_I** з ESP32-S3 і 4″ сенсорним екраном 480 × 480. Інтерфейс українською, прошивка побудована на ESP-IDF і LVGL.

- Годинник за київським часом і вулична температура Дніпра з Open-Meteo одразу поруч.
- Шестірня відкриває меню «Налаштування» з пунктами «Екран» і «Налаштування Wi-Fi».
- Сторінка Wi-Fi показує стан підключення, назву мережі, IP-адресу пристрою й сигнал у dBm з оновленням кожні 2 секунди.
- Карта повітряних тривог України зі статусом Дніпропетровської області. Дотик до карти чи статусу відкриває окремий перегляд: нерухома карта на всю ширину480px без обрізання країни та «Назад». Власні векторні піктограми ракети, БпЛА й літака позначають типи загроз для територій за Alerts.in.ua; збережені також КАБ, ППО й невідомі загрози. У лівому нижньому куті є компактна легенда всіх шести піктограм. Координат окремих повітряних цілей API не надає в задокументованій схемі. Екрани історії та деталей прибрано.
- Графік погодинних відключень **ЦЕК 5.2** на сьогодні й завтра з Alerts.energy. Дотик до шкали відкриває перелік інтервалів.

## Запуск

1. Встановіть **ESP-IDF 6.1** з підтримкою ESP32-S3.
2. Зберіть і прошийте проєкт за [інструкцією запуску](docs/setup.md).
3. Налаштуйте домашній Wi‑Fi в браузері телефона. Встановіть власні ключі API для тривог і графіка через USB.
