# Збірка й налаштування

## Середовище

Потрібні плата **Guition ESP32-4848S040C_I**, USB-кабель для даних, домашній Wi-Fi 2,4 ГГц та ESP-IDF 6.1 з інструментами для ESP32-S3. Команди нижче перевірено у Windows із Espressif Installation Manager. [Інструкція Espressif для Windows](https://docs.espressif.com/projects/esp-idf/en/v6.1/esp32s3/get-started/windows-setup.html)

## Перша збірка

Відкрийте PowerShell ESP-IDF 6.1 у корені репозиторію. Команди першого запуску завантажують компоненти за версіями з `dependencies.lock` та генерують конфігурацію плати.

```powershell
$env:PYTHONUTF8 = '1'
idf.py set-target esp32s3
idf.py bmgr -b esp32_4848s040
idf.py build
```

Для наступних збірок достатньо `idf.py build`. Готовий файл застосунку з’явиться в `build/home_dashboard.bin`. Для першого запису використовуйте команду нижче, яка також записує завантажувач і таблицю розділів.

## Прошивання

Під’єднайте плату через USB і знайдіть її COM-порт у «Диспетчері пристроїв» або виконайте `pnputil /enum-devices /connected /class Ports`. Підставте свій порт замість `COM3`.

```powershell
idf.py -p COM3 flash monitor
```

У журналі успішного запуску з’являється `Dashboard ready`. Для виходу із серійного монітора натисніть `Ctrl+]`. Перед наступним прошиванням або записом ключа звільніть COM-порт.

## Wi-Fi

1. Під час першого запуску ESP32 покаже назву мережі `PROV_DASH_…` і пароль. Для зміни мережі відкрийте кнопку **Wi-Fi** на головному екрані й виберіть **Змінити мережу**.
2. Підключіть телефон до мережі плати й відкрийте в браузері `http://192.168.4.1`.
3. Введіть назву і пароль домашньої мережі 2,4 ГГц на цій сторінці. Дочекайтеся статусу **Підключено** на екрані. Після синхронізації часу годинник покаже київський час.

Якщо телефон запам’ятав старий пароль точки доступу, забудьте мережу `PROV_DASH_…` і підключіться з поточним паролем з екрана. Якщо COM-порт зникає, спробуйте напряму підключити плату іншим USB-кабелем для даних і знову перевірте порт.

## Ключі API

Для температури ключ не потрібен. Для карти й графіка потрібні окремі ключі Alerts.in.ua та Alerts.energy. Закрийте серійний монітор і запустіть потрібну команду. Кожен ключ вводиться в окремому прихованому запиті.

```powershell
python main/tools/set_alerts_token.py --service alerts --port COM3
python main/tools/set_alerts_token.py --service energy --port COM3
```

Перезапустіть плату після запису ключів. Команда очікує таблицю розділів із цієї прошивки, тому перший запис ключів виконуйте після прошивання. [Деталі встановлення ключів](../main/tools/README.md)
