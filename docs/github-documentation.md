| docs/architecture.md | Актуальний опис запуску, задач, пам'яті, сховища та обмежень |

## Завантаження

Архів home-dashboard-architecture-github.zip містить README й нову/оновлену архітектурну документацію зі шляхами від кореня репозиторію. Розпакуйте його у checkout цього проєкту зі збереженням структури. Це overlay для репозиторію, а не автономна копія всього коду. Посилання на main/ і tests/ розраховані на наявні файли проєкту.

Перегляньте diff перед commit. Якщо є інші зміни, додавайте лише потрібні документаційні шляхи. Поточні користувацькі правки docs/performance-review.md не включені до набору. Набір не містить build/, SDK, credentials чи ключів API.

GitHub рендерить SVG без додаткової конфігурації Pages. HTML у перегляді файлів GitHub не виконується: завантажте всі сусідні HTML й відкрийте overview.html локально. Для вебхостингу можна окремо налаштувати GitHub Pages; створення набору не вмикає Pages і не публікує сайт.

## Оновлення схем

Редагуйте JSON, а не HTML/SVG. Команди finalize та export-svg, зафіксовані revisions і формат evidence наведені в [каталозі схем](archify/README.md). Після зміни вихідного коду перегляньте актуальність фактів і source ranges; не змінюйте тільки номер commit без повторного дослідження.
