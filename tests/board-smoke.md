# Перевірки дисплея, тача та Wi-Fi

Підготуйте плату ESP32-4848S040C_I, USB-кабель для даних, телефон із браузером і дві тестові мережі 2,4 ГГц. [Інструкція зі збірки та прошивання](../docs/setup.md)

| Дія | Очікуваний результат |
| --- | --- |
| Дочекатися запуску плати. | У серійному журналі з’являється `Dashboard ready`. Дисплей показує дашборд або налаштування Wi-Fi. |
| На платі без збереженої мережі підключити телефон до `PROV_DASH_…` з паролем з екрана та відкрити `http://192.168.4.1`. Спочатку ввести неправильний пароль домашньої мережі, потім правильний. | Після неправильного пароля налаштування можна повторити. Правильний пароль дає статус «Підключено», плата відкриває дашборд і закриває тимчасову точку доступу. |
| Перезавантажити плату. | Плата підключається до збереженої мережі без запуску тимчасової точки доступу. |
| Торкнутися графіка ЦЕК, потім «Назад». | Відкривається список інтервалів, кнопка повертає до головного екрана. |
| Натиснути «Wi-Fi», вибрати «Змінити мережу», налаштувати другу мережу й перезавантажити плату. | Плата відновлює підключення до другої мережі. |
| Перезапустити роутер і під час втрати зв’язку відкрити список інтервалів. | Тач працює. Статус Wi-Fi відновлюється після отримання IP. |

Для перевірки першого запуску використайте тестову плату з порожньою NVS. На вже налаштованій платі браузерне підключення можна перевірити через «Змінити мережу».
