# Перевірка налаштування Wi-Fi з браузера

## Інформація про з'єднання (FEAT-009)

RED до реалізації: `add_wifi_screen` створює лише стан, інструкцію й кнопку; API `dashboard_wifi.h` не надає SSID/IP/RSSI. `update_wifi` виходить за незмінного стану, тому не може оновлювати сигнал. Це перевірено за кодом, фізичний прогін не заявляється.

- Після підключення відкрити Налаштування → Налаштування Wi-Fi: стан «Підключено», фактична назва мережі, IPv4 пристрою та сигнал у dBm. Значення оновлюються кожні 2 с без повторного входу.
- Перевірити довгий SSID (32 байти), український SSID і зміну сигналу. Назва займає щонайбільше два рядки; IP/сигнал та кнопки не перекриваються.
- Вимкнути точку доступу: стан відновлення зв'язку, IP/сигнал/назва попереднього активного з'єднання більше не показані як чинні. До DHCP IP позначено «—». Після перепідключення показані нові фактичні дані.
- «Змінити мережу»: замість інформації про домашню мережу видно чинні інструкції тимчасової точки доступу. Введення пароля з телефона, завершення налаштування й автоматичний вихід на головний працюють як раніше.
- Перевірити Назад → меню, повторне відкриття, усі три теми, нічну палітру й запуск без збережених налаштувань. Не виводити домашній пароль або ключі в інтерфейс/журнал.

ESP-IDF build і `git diff --check` перевіряють збірку та зміни; читабельність, фактичні дані, дотики й відновлення перевіряються на платі.

1. Запустити плату й залишити її на екрані налаштування Wi-Fi.
2. На iPhone підключитися до `PROV_DASH_…` з кодом з екрана. Відкрити саме `http://192.168.4.1` у Safari. Сторінка має показати форму мережі.
3. Ввести назву домашньої мережі 2,4 ГГц і пароль. Після правильного пароля плата отримує IP, переключається на дашборд і закриває тимчасову точку доступу. Після неправильного пароля можна повернутися до форми й повторити.
4. Перезапустити плату й підтвердити збережене підключення. З домашньої мережі перевірити, що сторінка налаштування недоступна.
5. Переконатися, що застосунок ESP SoftAP Provisioning і далі може отримати версію сервісу через стандартний маршрут. Перевірити, що екран не блимає та COM3 не зникає під час підключення.

Окремо зафіксувати перезапуски, помилки USB і результат запиту погоди. Один успішний старт підтверджує завантаження прошивки.
