# Перевірка графіка Alerts.energy для ЦЕК 5.2

## FEAT-018 — область, оператор і черга

У Developer PowerShell з MSVC:

```powershell
C:/Espressif/tools/python/v6.1/venv/Scripts/python.exe tests/test_dashboard_energy_selection.py
C:/Espressif/tools/python/v6.1/venv/Scripts/python.exe tests/test_dashboard_recovery_source.py
C:/Espressif/tools/python/v6.1/venv/Scripts/python.exe tests/test_dashboard_workers.py
```

Нові тести перевіряють каталоги областей/операторів/черг, окремі Київ/Київщину, повторні номери черг у різних операторів, межі каталогів, пошкоджені відповіді й атомарність NVS при write/commit failure. UI suite виконує справжні callbacks: прокрутка/recycle, три послідовні майстри, помилка збереження, вихід і звільнення рядків. Worker suite включає застарілі графіки й каталоги A→B→A та 429/Retry-After під час зміни вибору; чинні concurrent20сценарії збережені.

На платі: відкрити «Налаштування → Відключення», вибрати Дніпропетровську область/ДТЕК/чергу, потім ЦЕК/іншу чергу та іншу область. До вибору черги чи після Назад чинна трійка не змінюється. Підписи головного екрана, деталей і системи відповідають вибору. Змінити місто — графік незмінний. Перезавантажити — трійка збережена. Перевірити порожній список, ключ/підписку, Wi-Fi, повторні відкриття й повну карту, мінімум два повторні active.json та energy HTTPS без TLS/OOM, усі теми/нічний режим. Ці target-перевірки не замінюються host PASS.

## Початкове покриття розкладу

- Вибрати тільки `initiator=dnipropetrovska_oblast_cek` і `queue=5.2` у відповіді області.
- Обробити 24 коди годин: 0 без відключення, 1 обидві половини, 2 перша половина, 3 друга половина. Можливі відключення показати окремим кольором.
- Відрізнити `NoShutdowns`, `WaitingForSchedule` та `EmergencyShutdowns`. Порожній масив при очікуванні або аварійному стані не дає зеленої шкали.
- Зіставити дати API з локальним часом Києва. Після опівночі вчорашній графік не має відображатися як сьогоднішній. В інтерфейс додати перемикання «Сьогодні» / «Завтра».
- За відсутності ключа, 401/403, 429, обриву Wi-Fi або зіпсованої відповіді показати відповідний стан. Після 429 врахувати Retry-After. Успішні попередні дані за потреби позначити застарілими.
- Локальне записування ключа Alerts.energy не зачіпає ключ Alerts.in.ua чи дані Wi-Fi.
