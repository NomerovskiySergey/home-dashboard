# Перевірки екрана дашборда

| Дія | Очікуваний результат |
| --- | --- |
| Запустити прошивку на екрані 480 × 480. | Українські підписи, температура Дніпра у °C, статус тривоги й графік ЦЕК 5.2 видно одночасно. |
| Переглянути карту України. | Межі областей читаються. Дніпропетровська область має окремий контур або маркер. Колір активної тривоги відповідає легенді. |
| Переглянути шкалу й торкнутися блока графіка. | Шкала показує всю добу, інтервали збігаються зі списком. Дотик відкриває список, кнопка «Назад» повертає до карти. |
| Натиснути блок Wi‑Fi. | Відкриваються налаштування мережі. |
| Перевірити запуск без збереженої мережі. | Екран показує ім’я точки доступу й код налаштування. Після підключення доступна головна сторінка. |

Збірка: `idf.py build` в активованому середовищі ESP-IDF 6.1. Для ручної перевірки записати збірку на ESP32-4848S040C_I.

## Годинник і Wi‑Fi

- До синхронізації часу головний екран показує `--:--`. Після синхронізації показує `ГГ:ХХ` за Києвом та оновлюється на початку нової хвилини.
- При підключенні, втраті мережі та під час налаштування блок Wi‑Fi змінює підпис. Дотик до блока відкриває налаштування.

## Нічний та економний режими

| Дія | Очікуваний результат |
| --- | --- |
| Відкрити «Екран» на платі без збережених налаштувань дисплея. | Три перемикачі вимкнені. «Назад» повертає на головний екран. |
| Увімкнути нічний режим і перевірити перехід через 22:00 та 07:00 за Києвом. | У проміжку 22:00–07:00 підсвітка працює з PWM 8%, а фон, картки та карта темнішають. Кольори станів тривог і відключень читаються. Після 07:00 повертається денна палітра й яскравість. |
| Увімкнути економний режим і зачекати 60 с без дотиків. Торкнутися кнопки Wi‑Fi, потримати палець і відпустити. | Підсвітка гасне. Перше натискання лише повертає підсвітку до поточної денної або нічної яскравості. Наступний дотик відкриває Wi‑Fi. |
| Залишити підсвітку вимкненою до наступних циклів опитування. | Wi‑Fi залишається підключеним, джерела оновлюються, а після дотику видно актуальні дані. |
| Увімкнути пробудження від тривоги й подати свіжі стани області «немає тривоги → тривога» під час гасіння. | Екран вмикається на поточній яскравості й показує головний екран. Повтор того самого активного стану після гасіння та застарілі дані його не будять. |
| Вимкнути пристрій і знову ввімкнути. | Перемикачі відновлюють збережені значення. Нічна яскравість застосовується після синхронізації часу. |
| Порівняти потужність на вході за звичайної яскравості, за 8% і з погашеною підсвіткою. | Записати виміряні значення для всіх трьох станів за однакового живлення і з підключеним Wi‑Fi. |

Автоматична перевірка на Windows у Developer Command Prompt:

```bat
cl /nologo /std:c11 /W4 /WX /I main tests\dashboard_display_mode_test.c main\dashboard_display_mode.c /Fo:build\ /Fe:build\dashboard_display_mode_test.exe
build\dashboard_display_mode_test.exe
```
